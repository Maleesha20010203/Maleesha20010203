## 🌟 About Me  

I’m **Maleesha Wickramasinghe**, a passionate and curious tech explorer from Sri Lanka 🇱🇰.  
My journey in technology started with a love for **Front-End Development**, but I quickly discovered my fascination with **Data Analytics and Data Science**.  

Today, I aim to combine both skills: building **beautiful, interactive web experiences** while also delivering **data-driven insights** that help businesses grow.  

Here’s what defines me:

- 📊 Skilled in turning **raw data into meaningful dashboards** using **Power BI** and Python libraries like **Pandas** and **NumPy**.  
- 💻 Experienced in **React, JavaScript, and UI/UX** to build intuitive and engaging websites.

- 🌍 Believer in tech’s power to **solve real-world challenges**.
